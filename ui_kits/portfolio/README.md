# Abbas Nawaz Portfolio — UI Kit

Single-product kit: the redesigned personal portfolio. Open `index.html` to see the full clickable recreation.

## Components

| File | What it covers |
| --- | --- |
| `index.html` | Full page demo with nav, hero, about, skills, experience, projects, research, contact, footer |
| `components.jsx` | All UI primitives: Nav, Hero, About, Skills, Experience, Projects, Research, Contact, Footer, plus Button, Pill, Eyebrow, Card |

Loads design tokens from `../../colors_and_type.css` and icons from Lucide CDN (substitution flagged in root README).
